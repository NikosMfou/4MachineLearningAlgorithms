# Machine Learning Algorithms

This project includes the implementation and analysis of clustering algorithms on synthetic and real-world datasets.

Algorithms Used
- K-Means
- DBSCAN
- Hierarchical Clustering
- HDBSCAN

Objectives
- Compare clustering performance across different algorithms
- Identify optimal number of clusters
- Detect noise and outliers
- Evaluate clustering quality

Evaluation Metrics
- Silhouette Score
- Inertia (for K-Means)
- Cluster visualization

Features
- Analysis on multiple datasets (Blobs, Moons, Circles, etc.)
- Parameter tuning (e.g. eps, min_samples)
- Comparison between algorithms
- Visualization of clustering results

Technologies
- Python
- scikit-learn
- matplotlib
- numpy
- hdbscan
